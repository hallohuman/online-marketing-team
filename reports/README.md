# Reports

One file per report: the numbers the team is allowed to quote. Each file names its source, the
period it covers, and the date it was read.

```
reports/2026-10-newsletter.md
  source: <the analytics or email tool, and the exact report name>
  period: 2026-10-01 to 2026-10-31
  read: 2026-11-01
```
